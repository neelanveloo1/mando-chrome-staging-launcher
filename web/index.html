  1. Install & sign in

    Unzip and open Install Mando Chrome.command. Install GitHub CLI if needed, then run gh auth login.

  2. Load staging once

    Open Mando Chrome, then load ~/Mando/StagingExtension in Chrome’s extensions page with Developer mode enabled.

  3. Add to your Dock

    Drag Mando Chrome from your Applications folder into the Dock. Open the included status command to connect this page.
